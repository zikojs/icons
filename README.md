# Zikojs Icons

A collection of official adapters and declarative components for integrating popular JavaScript icon libraries into the ZikoJS ecosystem.

## Adapters 

- [@zikojs/lucide](https://github.com/zikojs/icons/tree/main/packages/lucide) : Lucide Icons for ZikoJS.
- [@zikojs/feather](https://github.com/zikojs/icons/tree/main/packages/feather) : Feather Icons for ZikoJS.
- [@zikojs/fa](https://github.com/zikojs/icons/tree/main/packages/fa) : font aweome Icons for ZikoJS.
